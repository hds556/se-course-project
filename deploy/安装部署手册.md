# 在线购物系统 MVP —— 安装部署手册

> 版本：1.0.0 ｜ 组件：Java 17 + Spring Boot 3.4 + SQLite ｜ 交付物：`shopping-system-1.0.0.jar` / Docker 镜像

系统为单体应用：内嵌 Web 服务器，SQLite 单文件数据库（免安装数据库服务），前端静态资源已打进 jar。部署只需一个 JRE 环境或一个 Docker 容器。

> 本手册及其配套文件（`Dockerfile`、`docker-compose.yml`、`run.ps1`、`run.sh`、`shopping-system.tar`）统一放在仓库的 `deploy/` 目录；测试报告、测试用例、缺陷迭代记录放在 `docs/` 目录。

---

## 一、系统要求

| 项目 | 要求 |
| --- | --- |
| 方式 A：直接运行 | JDK/JRE 17 及以上 |
| 方式 B：Docker | Docker 20+（Windows 需 Docker Desktop） |
| 端口 | 3000（可改，见环境变量） |
| 磁盘 | ≥ 200 MB（含镜像/依赖） |
| 浏览器 | Chrome / Edge / Firefox 现代版本 |

## 二、部署方式 A：jar 直接运行

### 1. 获取构建产物

方式一：使用提交的 `shopping-system-1.0.0.jar`（随代码交付物提供，位于 `target/`）。

方式二：自行构建（需要 JDK 17 + 联网下载依赖）：

```powershell
.\mvnw.cmd clean package        # Windows
./mvnw clean package            # Linux / macOS
```

构建产物：`target/shopping-system-1.0.0.jar`。

### 2. 启动

```powershell
java -jar shopping-system-1.0.0.jar
```

如需自定义端口/目录（环境变量均可选）：

```powershell
$env:SHOP_PORT = "8080"; java -jar shopping-system-1.0.0.jar
```

### 3. 验证

浏览器访问：

- 买家页面：<http://localhost:3000/>
- 卖家后台：<http://localhost:3000/admin.html>

默认卖家账号 `admin`，初始密码 `admin1234`（**部署后请立即在后台修改密码**）。

### 4. 数据目录

首次启动自动在**工作目录**下创建：

```
data/shop.db     SQLite 数据库（全部业务数据）
uploads/         商品图片
```

升级/迁移时，将 `data/` 与 `uploads/` 两个目录整体拷贝即可，重启后数据保留。

## 三、部署方式 B：Docker（推荐）

镜像已发布至 Docker Hub：**`junhaofam/shopping-system:1.0.0`**，可直接拉取；也可使用交付包中的镜像文件 `shopping-system.tar` 离线导入，**均无需源码和构建环境**。

### 方式 0：从 Docker Hub 拉取（最简单）

```bash
docker pull junhaofam/shopping-system:1.0.0
docker run -d --name shopping-system -p 3000:3000 \
  -v shopping-data:/app/data -v shopping-uploads:/app/uploads \
  junhaofam/shopping-system:1.0.0
```

启动后访问 <http://localhost:3000/>。

### 交付包内容

| 文件 | 说明 |
| --- | --- |
| `shopping-system.tar` | Docker 镜像离线包（内含 JRE 17 与应用，约 171 MB） |
| `docker-compose.yml` | 运行配置（端口映射、数据卷） |
| `run.ps1` | Windows 一键运行脚本 |
| `run.sh` | Linux / macOS 一键运行脚本 |

### 方式 1：一键脚本（推荐）

将四个文件放在同一目录，执行：

```powershell
.\run.ps1          # Windows PowerShell
./run.sh           # Linux / macOS（chmod +x run.sh）
```

脚本会自动：检查 Docker → 缺镜像时从 tar 导入 → `docker compose up -d` 启动 → 健康检查直到页面可访问 → 打印访问地址。

### 方式 2：手动命令

```bash
# 1. 导入镜像
docker load -i shopping-system.tar

# 2. 启动服务（与 docker-compose.yml 同目录执行；数据落卷，容器删除不丢数据）
docker compose up -d
```

> 注意：交付的 `docker-compose.yml` 不含 `build` 配置，直接使用本地导入的镜像。

### 容器内配置说明

| 项目 | 容器内值 | 说明 |
| --- | --- | --- |
| 监听 | `0.0.0.0:3000` | 已映射宿主机 3000 端口 |
| 数据库 | `/app/data/shop.db` | 挂载卷 `shopping-data` |
| 图片 | `/app/uploads` | 挂载卷 `shopping-uploads` |
| 健康检查 | 每 30 秒探测首页 | `docker ps` 可见 healthy 状态 |

### 常用运维命令

```bash
docker logs -f shopping-system      # 查看日志
docker restart shopping-system      # 重启
docker rm -f shopping-system        # 停止并删除容器（数据在卷中保留）
docker compose down                 # compose 方式停止
```

## 四、环境变量（两种部署方式通用）

全部可选，不配置使用默认值：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SHOP_HOST` | `127.0.0.1`（容器内为 `0.0.0.0`） | 监听地址 |
| `SHOP_PORT` | `3000` | 监听端口 |
| `SHOP_DB_FILE` | `./data/shop.db` | SQLite 数据库文件路径 |
| `SHOP_UPLOAD_DIR` | `./uploads` | 图片上传目录 |
| `SHOP_DATA_FILE` | `./data.json` | 旧数据文件，仅首次迁移用 |
| `DEFAULT_SELLER_PASSWORD` | `admin1234` | 首次启动创建的卖家初始密码 |

## 五、部署后检查清单

- [ ] 访问买家页面返回正常界面
- [ ] 卖家后台可用默认账号登录，**并已修改初始密码**
- [ ] 卖家发布一件带图片的商品成功（图片出现在 `uploads/`）
- [ ] 买家提交意向，获得 8 位口令码
- [ ] 用口令码可查询进度
- [ ] 重启服务/容器后，商品、意向数据仍在（持久化生效）

## 六、常见问题

| 现象 | 排查 |
| --- | --- |
| 端口被占用 | 换端口：设置 `SHOP_PORT` 或改 `-p 8080:3000` |
| 页面打不开 | 查看日志 `docker logs shopping-system`；确认端口映射与防火墙 |
| 数据丢失 | 确认使用了 `-v` 卷挂载，或 `data/` 目录未被清理 |
| 镜像导入失败 | 确认 `shopping-system.tar` 与脚本/命令在同一目录，且磁盘空间充足 |

---

## 七、卸载

- jar 方式：停止进程，删除 jar 及 `data/`、`uploads/` 目录。
- Docker 方式：`docker rm -f shopping-system && docker rmi shopping-system:1.0.0`，如需清数据再执行 `docker volume rm shopping-data shopping-uploads`。
