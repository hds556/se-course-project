## 快速启动

```powershell
cd projectC3
.\mvnw.cmd package
java -jar target\shopping-system-1.0.0.jar
```

买家地址簿：<http://localhost:3000/addresses.html>（需登录）；卖家订单处理：<http://localhost:3000/seller-orders.html>（需后台登录）。
