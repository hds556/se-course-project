# 在线购物系统 MVP

Java 17 + Spring Boot 3.4 + SQLite，前端使用原生 HTML、CSS 和 JavaScript。本轮依据 SRS V2.0 完成商品目录相关任务，具体成果见[团队成果物](成果物/README.md)及[个人交付说明](成果物/我的任务/开发交付说明.md)。

## 本轮实现

- 多商品列表、二级类别筛选、分页与名称/描述搜索。
- 在售商品详情、多张商品图、富文本描述与内嵌图片。
- 冻结商品直链只读，已下架商品详情不可访问。
- 卖家维护两级类别，类别有商品引用时禁止直接删除。
- 发布多个商品，支持可选描述和 0～9 张 JPG/PNG 图片。
- 发布后仅库存与类别可编辑，库存调零自动售罄下架，版本校验防止陈旧编辑覆盖。

**团队联调尚未完成**：客户注册/登录/下单、队列与交易结果、手动下架、售罄重新上架和历史模块不在本次六组任务内。已有交易绑定时调零库存会返回 409，需先接入意向处置。详情目前没有可用的客户登录或下单入口。旧单商品、匿名意向、口令码和手动冻解路由已停用，返回 410。

## 运行与测试

需要 JDK 17；Maven 无需单独安装，项目自带 Wrapper。

```powershell
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

访问买家页面：<http://localhost:3000/>。访问卖家后台：<http://localhost:3000/admin.html>，未登录跳转登录页。初始账号 `admin`，默认初始密码 `admin1234`；可通过 `DEFAULT_SELLER_PASSWORD` 在首次初始化时设置。

打包后运行：

```powershell
.\mvnw.cmd package
java -jar target\shopping-system-1.0.0.jar
```

最终验证为 **23 项集成测试通过**，详情见[验证记录](成果物/我的任务/验证记录.md)。根目录 `ShoppingSystemBlackBoxTest.java` 对应旧版业务，不能用于本轮 V2.0 验收。

## 数据与配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| SHOP_HOST | 127.0.0.1 | 监听地址 |
| SHOP_PORT | 3000 | 监听端口 |
| SHOP_DB_FILE | ./data/shop.db | SQLite 文件 |
| SHOP_UPLOAD_DIR | ./uploads | 商品图和描述插图 |
| SHOP_DATA_FILE | ./data.json | 旧 JSON 数据来源 |
| DEFAULT_SELLER_PASSWORD | admin1234 | 首次创建卖家账号时的密码 |

新增 `category` 表；`product` 增加库存、类别、图片数组、描述纯文本和版本字段。旧商品缺少库存/类别时不进入新版列表，需团队确认后迁移。旧 JSON 匿名意向不导入，既有数据库中的旧记录保留且不展示。数据库与上传图片共同构成持久化数据，卖家会话在服务重启后失效。
