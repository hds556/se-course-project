# 截图目录

9 张截图对应客户管理模块（FR-S-13 查看客户列表 / FR-S-14 查看客户购买历史）的 9 个自检场景，全部在本地隔离环境（端口 3100、独立 SQLite 文件 `target/demo/shop.db`）中通过真实浏览器操作产生，演示数据为临时数据，不涉及正式数据库。

| 文件名 | 对应的验收点 |
| --- | --- |
| `01_后台客户管理列表第一页.jpg` | 列表四列字段齐全、按注册时间倒序、分页 |
| `02_客户列表第二页_默认交易地点未设置.jpg` | 未填默认交易地点显示"未设置" |
| `03_购买历史_成功两条.jpg` | 只列已终结交易、含下单与交易时间、分页 |
| `04_购买历史_失败一条.jpg` | 失败也计入历史（成功之外一律记失败） |
| `05_购买历史为空_仅排队中.jpg` | 排队中 / 交易中不进历史 |
| `06_买家端我的订单对照.jpg` | 与客户自己看到的记录集合一致（FR-S-14 验收第 3 条） |
| `07_未登录访问客户列表跳转登录.jpg` | 未登录不可见客户信息 |
| `08_未登录访问购买历史跳转登录.jpg` | 未登录不可见购买历史 |
| `09_客户列表独立页_已登录.jpg` | 独立页与后台入口共用同一组接口 |
