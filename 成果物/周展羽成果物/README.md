# 客户管理模块说明

卖家查看客户列表（FR-S-13）与客户购买历史（FR-S-14）。代码位于 `src/main/java/com/coursewise/shopping/customer/`。

| 功能 | 需求条款 | 设计 |
| --- | --- | --- |
| 查看客户列表 | SRS V2.0 FR-S-13（升级包 A.2：商家可以查看所有注册的客户信息） | [设计文档](设计/查看客户列表与客户购买历史_设计.md) |
| 查看客户购买历史 | SRS V2.0 FR-S-14（升级包 A.2：以及他们的购买历史） | 同上 |

## 边界

本模块是只读查询：只读 `customer`、`intent`、`product` 三张既有表，不写任何数据；

列表与历史查询复用买家端"我的订单"（`CustomerService.history()`）同一套查询与"成功之外一律记失败"的换算，保证卖家看到的记录集合与客户自己看到的完全一致（SRS FR-S-14 验收标准第 3 条）。
