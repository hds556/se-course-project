## 边界说明

本模块是**纯只读查询**：只读 `customer`、`intent`、`product` 三张既有表，不写任何数据。未改动任何实体类、枚举与建表逻辑，数据库无需迁移；`data/`、`uploads/` 由 `.gitignore` 排除。

列表与历史查询复用了买家端"我的订单"（`CustomerService.history()`）同一套查询与"成功之外一律记失败"的换算逻辑，保证卖家看到的记录集合与客户自己看到的完全一致（SRS FR-S-14 验收标准第 3 条）。

商品目录、交易、类别分属队友模块，本模块只依赖其既有接口，未改动队友代码。禅道任务编号以禅道实际记录为准。
