## 演示数据与发布边界

- 自检使用独立端口 3100 与独立 SQLite 文件（`target/demo/shop.db`），不读写正式数据库。
- 演示数据：12 位客户（buyer01~12，buyer02 故意不填地点）、2 件商品、3 笔已终结交易 + 1 笔排队中意向；全部为临时数据，不随仓库提交。
- 演示数据由 HTTP 接口逐笔构造（注册 → 下单 → 发起交易 → 标记结果），未直接改库。
- 未部署到外部服务器；禅道任务状态以实际记录为准。

## 已知限制

1. 客户列表的排序（注册时间倒序）与每页 10 条是本轮约定（SRS T-21 待确认项），不作为验收依据。
2. 同一秒注册的客户按自增 id 兜底排序。
3. 历史中的商品名是下单时快照，商品改名后仍显示旧名（BR-36 要求）。
4. 列表与历史均为只读，无搜索 / 筛选 / 导出（EX-06）。

以上均在设计文档的"遗留"一节写明。
