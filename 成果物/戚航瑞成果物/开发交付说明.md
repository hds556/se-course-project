## 修改前的问题

1. 后台编辑仅有库存和类别，缺少商品内容维护。
2. 发布页提示名称、价格、描述、图片固定，与本次迭代不符。
3. 冻结状态仍可通过普通直链查看，而收藏列表链接没有受保护的详情例外入口。

## 实现过程

1. 保留原库存 PATCH 接口，新增 multipart PUT 内容接口，避免将库存更新混入商品信息保存。
2. 服务层先鉴权，再检查在售状态、库存与 version；名称去除首尾空白，最多 128 个 Unicode 字符；价格转整数分。
3. 校验保留图片属于当前商品且不重复，与新增图片合计不超过 9 张。新增图片同时验证扩展名、MIME 和实际解码，单张最多 5MB。
4. 新增图片依次追加到保留图片后，第一张为主图。支持删除所有图片后使用占位图。旧文件保留，避免其他引用失效，暂未实现图片垃圾回收。
5. 富文本经过 Jsoup 白名单净化，仅允许本地已存在上传图片；同步维护 descriptionText 供搜索。
6. 编辑页面加载字段和版本，支持图片保留复选框、新增预览、富文本格式与描述插图。下架商品禁用编辑区域；服务端也拒绝保存。
7. 普通详情拒绝 frozen、sold、depleted、withdrawn 和零库存；收藏入口验证 customer_session 和本人收藏记录后返回只读详情。
8. 使用实际内容编辑接口验证订单快照，替换原来直接修改数据库价格的测试方式。

## 接口

| 方法与路径 | 参数与约束 |
|---|---|
| POST /api/products | multipart：name、price、stock、categoryId 必填；description、images 可选；seller_session |
| PUT /api/admin/products/{id}/content | multipart：version、name、price、categoryId；description 可空；retainedImages 重复字段传保留路径；images 传新增文件 |
| GET /api/products/{id} | 普通详情，不可售或库存为 0 返回 404 |
| GET /api/products/{id}/favorite-detail | customer_session；未收藏返回 404，未登录返回 401；本人的收藏可只读查看 |
| GET /api/admin/products/{id} | seller_session；返回完整信息与 readOnly |

内容保存不传 retainedImages 表示删除所有旧商品图，不传 description 表示清空描述。新图片全部校验完成后才写入；事务失败时清理本次新建文件。非法字段返回 400，陈旧版本与不可售内容编辑返回 409。
价格范围沿用现有工程：0.01 至 9,999,999.99 元，最多两位小数。描述与商品图选填。

## 联调边界

- 内容编辑不写 stock、status、offline_reason，不修改订单或订单明细。
- 发布时初始化库存和 active 状态沿用原工程；订单库存变化和商品状态机仍由对应同学维护。
- 原 PATCH /api/admin/products/{id} 是既有库存/类别维护接口，继续保留兼容，未重写库存状态逻辑。旧交易队列页面和机制仍存在，等待谭梓良统一拆除，不能将此模块完成等同于整个 B 迭代完成。
- 版本字段使用现有 JPA @Version；SQLite 当前单实例的写锁与事务保持原实现。
- 收藏页添加 from=favorite 仅选择入口，权限以服务端会话和收藏记录为准，不能靠修改 URL 绕过。
