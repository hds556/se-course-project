## 关键覆盖

| 场景 | 证据与结论 |
|---|---|
| 修改名称、价格、类别、描述、图片 | 持久化成功，搜索匹配新描述；库存和状态不变 |
| 图片保留、追加、清空 | 原图顺序保留，新图追加；清空后返回占位图 |
| 伪造/重复保留路径 | 400，不允许引用其他商品图 |
| 第 10 张图、损坏格式、超 5MB | 400，发布失败无新商品或文件残留 |
| 非法价格与字段 | 0、负数、三位小数、指数形式等拒绝 |
| 旧版本覆盖 | 409 |
| 不可售编辑 | frozen / sold / depleted / withdrawn 均拒绝内容保存 |
| 普通详情直链 | 不可售状态返回 404 |
| 订单快照 | 商品由 10 元改为 120 元，原订单单价仍 10 元、两件合计 20 元 |
