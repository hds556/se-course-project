# 接口自检记录（挑战需求B · 开发B）

- 被测版本：projectB 分支，本次新增 seller 模块后的本地构建
- 运行方式：java -jar target/shopping-system-1.0.0.jar，独立 SQLite 库与独立上传目录（不污染仓库内 data/shop.db）
- 调用方式：脚本直连真实服务，无 mock；下表即服务端原始响应
- 覆盖需求：14207 推进订单状态 / 14208 卖家取消订单 / 14209 查看商品订单记录 / 14214 查看客户购买历史
- 与自动化测试的关系：本文档是"对着运行中的服务打接口"的实测记录，自动化用例见 src/test/java/com/coursewise/shopping/SellerOrderIntegrationTest.java
- 演示数据：4 件商品（#1 钢笔 · 晨光 M1 / #2 手账本 · 方格 / #3 墨水 · 兰黑 / #4 蓝牙耳机）、
  3 位客户（#1 alice / #2 bob / #3 carol）、6 笔订单（#1 ~ #6）。下文出现的 orderId / productId / customerId 即这些编号。

==============================================================================
