# 截图目录

12 张截图对应 12 个禅道任务，全部在本地隔离环境（独立端口与独立 SQLite 文件）中通过真实浏览器操作产生，演示数据为临时数据，不涉及正式数据库。

| 文件名 | 对应的验收点 |
| --- | --- |
| `01_未登录详情无下单入口.jpg` | 未登录无可用下单入口 |
| `02_登录后提交成功排队位次.jpg` | 提交即生成记录、库存不变 |
| `03_我的订单进行中两条记录.jpg` | 可重复提交、按时间排序 |
| `04_后台交易管理队列.jpg` | 队列与位次可见 |
| `05_发起交易后列表不可见.jpg` | 冻结后列表不可见 |
| `06_冻结商品直链只读.jpg` | 直链只读、不可下单 |
| `07_标记成功库存减一.jpg` | 库存扣减、回在售 |
| `08_库存归零已售终态.jpg` | 归零进终态、计入历史 |
| `09_失败重新排队到队尾.jpg` | 重排刷新下单时间 |
| `10_手动下架买家端无法访问.jpg` | 下架后不可访问 |
| `11_售罄补货仍为下架.jpg` | 补货不自动上架 |
| `12_重新上架恢复在售.jpg` | 重新上架、原队列不恢复 |

## 自检

双击上一层的 `截图画册.html`，12 张应全部正常显示；也可直接看 [截图索引](../截图索引.md) 的逐张说明。
